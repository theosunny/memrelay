# MemRelay v0.1.0 — one memory for all your AI agents

_First public preview, 2026-10-18. Apache-2.0._

MemRelay connects the AI agents you already use to **one personal memory you own**. The
memory is plain Markdown on your disk, every memory records where it came from, and
**nothing is saved until you approve it**.

## Highlights

- **`memrelay connect --all`** finds your agents, previews each config change, and asks
  before writing. Every write is backed up, and `connect rollback <agent>` restores it.
  - Auto-connect: Claude Code, Cursor, Claude Desktop, Windsurf, Codex (TOML, comments
    kept), Gemini CLI, VS Code Copilot, Cline (CLI and VS Code extension).
  - Guided setup (prints the config and steps, writes nothing): 豆包, Kimi, 通义千问.
- **Capture** reads your local agent history incrementally (Claude Code, Codex, Gemini CLI)
  and turns your own statements into candidate memories. `capture all --watch` keeps
  watching, and `autostart install` registers it with launchd, systemd --user or Task
  Scheduler; `--dry-run` shows the entry first.
- **Import** handles ChatGPT and Claude.ai data exports. It finds them in Downloads and
  asks before importing each one; raw transcripts are archived with Basic Memory's own
  importers.
- **Review** happens in the CLI (`memrelay inbox …`) or a local web page
  (`memrelay review`, 127.0.0.1 only).
- **Gateway**:
  - Agents get five whitelisted MCP tools: `get_profile`, `recall`, `read_memory`,
    `recent` and `propose_memory`.
  - Proposals go to the inbox.
  - Secrets are redacted, and possible prompt injections are flagged.
- **Core profile**: `memrelay profile build` summarises reviewed memories, and every line
  links to its source note.
- **China-friendly**: if huggingface.co is unreachable, the embedding model download
  falls back to `hf-mirror.com`.

## Install

```bash
uv tool install basic-memory
uv tool install "git+https://github.com/theosunny/memrelay@v0.1.0#subdirectory=packages/core"
memrelay init && memrelay connect --all
```

(Not on PyPI yet. Windows: install uv first, see README.)

## Tested

- CI runs on Ubuntu, macOS and Windows with Python 3.11 and 3.13, plus an integration job
  against a real Basic Memory 0.23.x.
- 132 tests (unit + integration).

## Known limitations

- Cursor chat history is not captured: it lives in an undocumented internal database.
- The 豆包 / Kimi / 千问 desktop apps have no documented MCP config path, so setup is
  guided only.
- Gemini CLI's legacy `.json` sessions are not read; only `session-*.jsonl` is.
- Autostart on macOS and Windows is covered by unit tests; real-machine reports are welcome.
- CLI messages are mixed Chinese/English; full i18n is planned.
- The rule-based extractor is conservative. For better recall, plug in an
  OpenAI-compatible LLM (`extractor = "openai"`).
