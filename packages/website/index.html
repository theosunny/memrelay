忆桥

一份记在你自己设备上的记忆。电脑上的分身可以问，手机上可以看。同一份记忆，换一张面。

同步出去的只有密文。打开笔记的钥匙不离开设备。

下载

macOS

即将发布。安装包还没挂到 GitHub Releases 时，从源码构建。

即将发布

在 Mac 上，进入仓库的 packages/desktop：

npm install
npm run tauri build

未签名的 忆桥分身.app 在 src-tauri/target/release/bundle/macos/，.dmg 在 src-tauri/target/release/bundle/dmg/。第一次请右键打开。从访达启动前先安装命令行程序：

uv tool install "git+https://github.com/theosunny/memrelay#subdirectory=packages/core"
uv tool install "git+https://github.com/theosunny/memrelay#subdirectory=packages/sync"

手机

部署本站之后，用手机浏览器打开 /m/。把它加到主屏幕即可当成分身入口。

要打成 iOS / Android 安装包，用仓库里的 packages/mobile（需要 Xcode 或 Android Studio）。

打开手机版

同步

桌面和手机填同一个同步服务地址。改地址之后，在电脑上重新生成配对码，再在手机里粘贴。

官方同步

地址 https://memrelay-sync.preview.tencent-zeabur.cn

桌面和手机的「同步服务」填这个地址。已经装好的应用在设置里改即可，不用重编。Zeabur 共享集群 2026-12-01 起暂停，2026-12-31 停止。

自建同步

在你自己的机器上：

memrelay-sync --host 0.0.0.0 --port 8790

两端的同步服务填 http://那台机器:8790。这台进程没有 TLS，不要把 8790 暴露到公网。公网用官方同步的 HTTPS。

只在本机用时，填 http://127.0.0.1:8790。桌面应用在这个端口空着的时候会自己拉起一份。

钥匙

配对串里的钥匙只留在设备上。服务器保存密文，看不到笔记正文，也打不开库。
