我偏好什么？

饮品.md · 已审核 · 只在本机

  • 接入就备份

    自动写 MCP 配置。不合意就回滚，不留一手改过的文件。

  • 默认自动，护栏常在

    高置信、可信来源直接入库。人工审核是可选的严格模式。

  • 画像带来源

    核心画像从已审核记忆生成。每条都能走回原来的笔记。

  • 分身只起草

    风格和决定只取自你写过的话。草稿不会自己发出去。

留在设备上

正文留在你的设备上。

  • 本机 Markdown

    记忆库是普通文件。你可以打开、改、搬走。

  • 同步只见密文

    官方同步存不下笔记原文。配对用的钥匙不离开设备。

  • 网关不放行乱写

    智能体除了提议新记忆，不能改已经审核过的笔记。

下载

在 Mac 上打开你的分身。

即将发布。还没有安装包时，展开下面的命令自己构建。

查看 Releases 打开手机版
从源码构建

在 Mac 上进入 packages/desktop：

npm install
npm run tauri build

未签名的应用在 src-tauri/target/release/bundle/macos/，dmg 在 src-tauri/target/release/bundle/dmg/。第一次请右键打开。从访达启动前先安装：

uv tool install basic-memory
uv tool install "git+https://github.com/theosunny/memrelay#subdirectory=packages/core"
uv tool install "git+https://github.com/theosunny/memrelay#subdirectory=packages/sync"
memrelay init
memrelay connect --all
